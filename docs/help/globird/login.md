# Logging in to GloBird

The app needs the email address and password you log in to the GloBird customer portal, [myaccount.globirdenergy.com.au](https://myaccount.globirdenergy.com.au), with.

The app saves both in the profile, and keeps the portal's session in its cache, so that it logs in as rarely as it can: once, and again only when GloBird ends the session. If a login fails, e.g. because the password has changed or GloBird asks for a captcha, the app does not try again until you log in on this page, so that it cannot lock your account. If GloBird asks for a captcha, log in once on GloBird's web site, then try again later.

Your email address and password only go to GloBird, the app has no server of its own.
