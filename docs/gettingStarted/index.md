# Installation
There are separate pages containing step by step instructions to install the application on [MacOS](osx/index.md) and [Windows](windows/index.md).

The macOS app is signed and notarized by Apple, so it installs and opens like any other app. The Windows installer is
not signed yet, so Windows warns about it, and there is an extra step to run it: please read the
[Windows](windows/index.md) instructions, even if you are familiar with installing applications.
